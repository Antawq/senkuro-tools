# Changelog (Журнал изменений)

Формат основан на соглашении [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [2.1.6] - 2026-10-12

### Добавлено (Added)
- **Оценка стоимости карт в F на странице профиля**:
  - Виджет монтируется прямо в шапку профиля рядом с ником пользователя (`.client-header` рядом с уровнем и заголовком `h1`).
  - Отображается на страницах `https://senkuro.com/users/<slug>` и на вкладках карточек `https://senkuro.com/users/<slug>/cards`.
  - Автоматический запуск расчёта при открытии страницы с анимацией загрузки (`💎 Считаем F...` / `Карт: X...`).
  - Всплывающее интерактивное окно с подробной статистикой (Popover):
    - Общая стоимость в F
    - Число целых карт и осколков
    - Разбивка банковских карт по рангам (`S`, `A`, `B`, `C`, `D`, `F`)
    - Разбивка осколков по рангам
    - Стоимость и количество карт ранга `R` (при наличии)
    - Кнопка «↻» для принудительного сброса кэша и перерасчёта.
- **Публичные Persisted GraphQL-запросы (без необходимости авторизации)**:
  - Функция `executePersisted` в `extension/utils/graphql.ts`.
  - Запросы через официальные SHA256 хеши Senkuro из модуля `zzz`:
    - `fetchUser` (`4bef9abf7c5ad00af59085a24e9c52ad3f095d8adc1e9251b65c7eece2bb07e6`)
    - `fetchUserCards` (`e426e266f581825cf223ad2d30e133e95404113093576629481fdda992d47016`)
  - Теперь можно смотреть ценность карт **абсолютно любого пользователя**, даже если текущий пользователь не авторизован на сайте.
- **Кэширование в `sessionStorage`**:
  - Быстрый доступ к рассчитанной сумме с TTL 10 минут. При переходах между вкладками профиля значение выводится мгновенно (0 мс).
- **Юнит-тесты**:
  - `extension/tests/profile-dom.test.ts`: тесты монтирования в шапку, кэширования и SPA-роутинга.
  - `extension/tests/profile-cards.test.ts`: тесты выборки данных и расчёта F.

### Изменено (Changed)
- `content.ts`: `MutationObserver` теперь автоматически отслеживает монтирование шапки профиля при навигации через Nuxt/Vue SPA роутер.

## [2.1.4] - [2.1.5] - 2026-10-12

### Добавлено (Added)
- **Мгновенный рендеринг ценников (Instant Badges)**:
  - Убрано ожидание загрузки картинок (`img.addEventListener('load')`).
  - Ценники крепятся сразу по `slug` ссылки карты (`a.card-collect[href]`).
- **Очередь и батчинг на `requestAnimationFrame`**:
  - Полностью устранён Debounce (250 мс) и задержка простоя (500 мс).
  - Накопление новых карточек в `Set<HTMLAnchorElement>` и рендер в следующем кадре анимации.

### Исправлено (Fixed)
- Значительное ускорение отрисовки цен на больших страницах и в гаче/инвентаре.
