# Политика конфиденциальности SenkuTools

SenkuTools не собирает, не отслеживает и никуда не отправляет данные пользователей.

## Как расширение работает с данными
- Настройки: хранятся только в браузере (chrome.storage.local).
- Куки: расширение читает сессионную куку Senkuro на странице, чтобы показать данные токена. Кука никуда не передается.
- Буфер обмена: копирует имя карты или постер только при нажатии на кнопку копирования.

## Внешние сервисы
У расширения нет своих серверов, аналитики, трекеров и рекламы. Все работает локально в браузере.
